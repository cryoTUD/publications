# A nanobody toolbox to probe Guanylate-binding protein coat assembly and function

This repository contains all scripts needed to reproduce the figures from the paper "A nanobody toolbox to probe Guanylate-binding protein coat assembly and function" (2026) by Lennart L. Pagani, Tanja I. Kuhm, Cecilia de Agrela Pinto, Elise G. Perton, Mireya Arents, Ngoc M. P. Nguyen, Els
Pardon, Jan Steyaert, and Arjen J. Jakobi.
