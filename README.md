# Repository of figure reproducibility scripts for AJ lab publications

This repository contains scripts from the [AJ lab](https://cryoem.tudelft.nl/) for reproducing figures and analyses from the publications listed below. Click on the links below to open the corresponding repository branch with the relevant scripts and supporting materials.

1. Bharadwaj, A. & Jakobi, A. J. *Electron scattering properties of biological macromolecules and their use for cryo-EM map sharpening*. Faraday Discussions **240**, 168–183 (2022)    
   Branch: https://github.com/cryoTUD/publications/tree/ElectronScattering_2022

2. Bharadwaj, A., de Bruin, R. M. M. & Jakobi, A. J. *Confidence-guided cryo-EM map optimisation with LocScale-2.0*.
   bioRxiv (2025)    
   Branch: https://github.com/cryoTUD/publications/tree/LocScale_2025

3. Bharadwaj, A., Veerbeek, L. & Jakobi, A. J. *Interactive segmentation of membrane and membrane mimic densities in cryo-EM maps*.
   bioRxiv (2026)     
   Branch: https://github.com/cryoTUD/publications/tree/SURFER_2026
